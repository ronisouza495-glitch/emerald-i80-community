COMECE AQUI

Quatro passos. Uma vez só.

01

Tenha o cliente

Use uma instalação completa do WoW 3.3.5a, build 12340. Abra sempre pelo Wow.exe.

02

Instale o Tailscale

Baixe para Windows ou Android, faça login em sua própria conta e deixe o aplicativo conectado.

Baixar Tailscale ↗
03

Aceite o convite

Abra o link enviado pelo dono do servidor. Ele compartilha somente a máquina do Emerald, não toda a rede.

04

Configure e jogue

Edite Data\enUS\realmlist.wtf e use o IP informado pelo dono. Depois entre com sua conta.

CONFIGURAÇÃO

A única linha que muda.

O dono do servidor envia o IP Tailscale. Substitua o exemplo abaixo e salve o arquivo.

set realmlist 100.x.y.z

QUER HOSPEDAR TAMBÉM?

O mesmo kit funciona em outro Emerald.

Execute o inicializador e selecione sua cópia local autorizada. Ele cria uma instalação separada, gera credencial local aleatória, aguarda o MySQL autenticar e inicia AuthServer e WorldServer. A pasta original não é modificada.
